AI LOTO Monitoring

A practical guide for operators, managers, workers, viewers and administrators using the web interface to monitor access, configure devices and understand safety status.

SICKBioStar 2 integrationSICK SIG300Visionary AI cameras

1. What the system does

AI LOTO Monitoring combines worker authentication, gate control and AI-based people monitoring. It receives successful authentication events from BioStar 2, determines whether the worker is entering or leaving, controls the assigned gate through a Gateway Device (SICK SIG300 in the current deployment), compares registered workers with Visionary AI detections, and presents a simplified safety picture on the Monitoring page.

2. Sign in

Open the site URL supplied for the installed system. Enter your LOTO account email and password, then sign in. After login, the sidebar shows only the pages permitted for your account.

Admin vs Viewer

Administrator

Full system configuration and administration. Admin can manage gateways, gates, cameras, access devices, shopfloor layouts, LOTO users, BioStar user management, settings, roles/permissions and logs.

Viewer

Primarily read-only. Viewer can monitor the system, inspect histories/device details and—by the default role definition—send manual Gate Open/Close commands. Create/Edit/Delete controls are hidden on management pages.

Viewer noteThe Active Workers table can render a manual Tag Out control, but the default Viewer role does not have the corresponding write permission. If a Viewer tries an action not granted to the role, the backend can reject it. Use an authorized account for worker-state correction unless permissions were intentionally changed.

4. Recommended setup order

  1. Prepare BioStar 2 and scanner networking. Confirm the BioStar server is reachable and configure its URL/login in LOTO Settings. Assign each Suprema scanner a unique, stable site IP and confirm BioStar can reach its device port.
  2. Create Gateway Devices. Add Gate Control SIG300 gateways and the Alarm gateway. Confirm they show Connected.
  3. Create/synchronize Gate Access Devices. In Gate Access Device Management, enter the scanner's exact IP and port (normally 51211), run TCP Search, select the detected device and save. LOTO registers/synchronizes the BioStar device reference automatically.
  4. Create Gates. Assign the Gate Control gateway, access device and the three required gate signals: FlexLock DO, FlexLock AUX DI and MB1 Sol DO.
  5. Create Cameras. Enter the camera address, human-count endpoint, people-count volume IDs and fall-evaluation IDs.
  6. Upload Shopfloor Layout. Activate the plan, place gates and adjust rotation.
  7. Complete System Settings. Open the Settings page and make sure all required configuration values are present and suitable for the installation before final review.
  8. Validate on Monitoring. Perform controlled test scans and verify active worker, gate state, AI count, System Trust and Site Safety Status.
