Reference & Glossary

1. Runtime state glossary

Term Meaning
TAG_IN / IN Accepted authentication when the worker has no active inside state.
TAG_OUT / OUT Accepted authentication when the worker is already active inside.
OPENING / CLOSING Physical gate transition is in progress.
FAULT Gate command failed and requires investigation/retry.
Connected Device/gateway is responding.
Disconnected Communication currently failing but failure threshold may not yet be reached.
Unavailable Device/source is unavailable according to current health logic.
System Trust GOOD Required monitoring sources are sufficiently available/current.
System Trust NG Required source availability is degraded.

2. SIG300 pin mapping used by the software

Pin REST process-data field
Pin 2 iqValue
Pin 4 cqValue
Pin 5 iq5Value

Gateway process data is read/written at the SIG300 IO-Link REST path for the configured master port. The user interface handles this mapping; operators normally work with Port, Pin, Direction and Function.

5. Safety status quick reference

Status Interpretation
SAFE No registered/AI-detected people, all gates closed, trusted sources available, no active fall/mismatch/transition/fault.
WARNING Workers are inside and registered count equals AI count, with required source data available.
UNSAFE Camera/Alarm gateway unavailable, gate state unknown, AI detects more people than registered, or a gate fault exists.
UNKNOWN Current facts cannot be classified yet.

6. Authentication methods

  • Fingerprint — BioStar event type contains FINGERPRINT.
  • Face — event type contains FACE.
  • NFC — card/NFC success event; internally classified as CARD.
  • Unknown — accepted success event whose credential family is not recognized.

7. Source-of-truth boundaries

BioStar 2

Worker users, biometric/card credentials, physical access-device registration/advanced settings.

AI LOTO

Access-device-to-gate reference, active worker presence, access event history, gate state machine, gateway pin mapping, Visionary configuration, shopfloor layout and site safety status.
